# RSI adapter: dfm-ssm-external-wikitext-ppl

Generated by `skills/rsi-adapter` from `examples/dfm_ssm_external.json`.

This adapter is **target-owned**. RSI core does not import it. It is wired to
`scripts/finetune_dfm.py` and the lm-eval wrapper `bench/dfm_lm_eval.py`.

`remote.env` is injected by RSI's `RemoteRunner` into the SSH command. It is
not present when you invoke `run_experiment.py` directly on the host/container;
set the same variables (or pass `--data` / `--checkpoint`) for a local test.
The tokenizer can be a local directory, e.g.
`RSI_DFM_TOKENIZER=/home/sl/mamba/checkpoints`; it is validated before
training.

## Contract

```text
python run_experiment.py --repo <candidate worktree> --scope <scope> --out <report.json>
```

Report on success:

```json
{"metrics": {"word_ppl": 0.0}, "status": "ok"}
```

The adapter must exit non-zero and write `{"metrics": {}, "status": "failed"}`
on any failure. RSI treats a failed run as data, never as an improvement.

## Metrics

| name | direction | tolerance | bounds |
|---|---|---|---|
| `word_ppl` | `min` | `1.0` | `None` |

## Target defaults

- target repo: `/repos/mamba`
- adapter install path: `bench/rsi_dfm_train_eval.py`
- scopes: `subset, full, ablation, rebuttal`
- env prefix: `RSI_DFM`

## Install on the benchmark ref

```bash
TARGET_REPO=/path/to/target ./setup.sh
```

The setup script copies both `run_experiment.py` and `dfm_lm_eval.py` to
`bench/rsi_dfm_train_eval.py` and `bench/dfm_lm_eval.py` on `rsi-bench` (or
`RSI_BENCH_REF`). Update the fixture's `repo_ref` to that ref if needed.

## Validate before running RSI

```bash
python3 run_experiment.py --help
env -u RSI_DFM_TRAIN_DATA python3 run_experiment.py \
  --repo /path/to/target --scope subset --out /tmp/missing.json; echo "exit=$?"
# expected: exit=1 and {"metrics": {}, "status": "failed", ...}
python3 run_experiment.py --repo /path/to/target --scope subset --out /tmp/report.json
python3 -m json.tool /tmp/report.json
```

`--mock` in RSI never executes this file. Use `--runner subprocess` for a real
adapter check.
